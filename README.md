# meus-desafios-criativos
🎯 Desafio Criativo: Extraindo Insights do Feedback de Clientes Bancários

Atue como analista de dados e consultor de negócios de um banco.

Sua tarefa é analisar feedbacks de clientes sobre ligações ativas dos gerentes de agência para identificar os principais obstáculos e motivos de recusa na oferta de produtos financeiros.

O resultado será usado pelas equipes Comerciais e de Gerência de Agências para apoiar a melhoria das abordagens de vendas e o aumento da taxa de conversão.

A entrega deve conter um resumo das objeções, uma tabela por tipo de recusa e recomendações práticas para os gerentes.

O resultado será considerado bom se for direto, focado nos gargalos de vendas e fácil de aplicar no dia a dia da agência.

Contexto: Estou trabalhando com feedbacks de clientes bancários relacionados a chamadas da gerência para oferta de investimentos e produtos financeiros.

Dados disponíveis: A base contém produto oferecido, resposta do cliente (Aceitou/Recusou), justificativa da recusa e canal utilizado.

Instruções de análise:

  1. Classifique os feedbacks por produto oferecido, tipo de objeção (como falta de interesse, receio de segurança ou rentabilidade) e nível de impacto na conversão.

  2. Identifique os principais padrões, problemas, elogios e oportunidades.

  3. Aponte evidências nos dados fornecidos.

  4. Sugira ações práticas para os gerentes de agência e a equipe Comercial.

Formato da resposta:

Resumo executivo, tabela categorizada por motivo de recusa e lista de recomendações para contorno de objeções.

Restrições:

* Use apenas os dados fornecidos.
* Não invente números, causas ou conclusões.
* Não exponha dados pessoais ou sensíveis.
* Se houver informação insuficiente, indique a limitação.
* Use linguagem simples, direta e focada em resultados, voltada para orientar estratégias de melhoria na abordagem e aumentar a conversão.
